# Sonalis Client 5.2.0

- Windows istemcisinin ürün, PE ve kurulum sürümleri 5.2.0 olarak eşitlendi.
- Aurora arayüzü, Guardian güvenli medya inceleme altyapısı ve kanal tabanlı mesajlaşma tek sürüm hattında birleştirildi.
- İmzalı manifest, SHA-256 ve Ed25519 paket doğrulaması korunur.
- Stable paket için Authenticode imzası zorunludur; imzasız doğrulama derlemesi yalnız canary kanalında üretilir.
- Windows 10/11 x64, statik MSVC runtime, libopus ve RNNoise hedefleri korunur.
