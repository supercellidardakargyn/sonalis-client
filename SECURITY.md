# Security policy

## Desteklenen sürümler

Yalnız en güncel `5.2.x` release güvenlik güncellemeleri alır. Eski release'ler
yalnız geçiş süresi boyunca çalışabilir ve güvenlik desteği almayabilir.

## Güvenlik açığı bildirme

Lütfen güvenlik açığını public issue olarak yayımlamayın. GitHub deposundaki
**Security → Report a vulnerability** seçeneğini kullanın. Bu kanal kullanılamıyorsa
https://sonalis.tr/support üzerinden başlığında `SECURITY` bulunan özel bir destek
talebi açın.

Rapora mümkünse etkilenen sürüm, yeniden üretme adımları, beklenen/gerçek davranış
ve etkinin kısa açıklamasını ekleyin. Parola, token, private key, gerçek mesaj
içeriği veya üçüncü kişilerin kişisel verisini göndermeyin.

Alındı bildirimi için hedef süre 72 saat, ilk değerlendirme için hedef süre yedi
gündür. Düzeltme yayımlanana kadar ayrıntıların gizli tutulmasını isteyebiliriz.

## Güvenlik sınırı

Bu depo native istemciyi kapsar. Merkezi Sonalis hizmetindeki bir açık için de aynı
özel bildirim kanalı kullanılmalıdır; kapalı sunucu kaynak kodu bu depoda bulunmaz.
